# APS Academy

A 30-day, browser-based onboarding program for future AI Product Studio contributors.

## Goal

By Day 30, a learner should be able to:

- explain the core APS trust model in plain language;
- read basic Python used in APS-style code;
- use Git and understand diffs, commits, branches, and pull requests;
- understand tests, verification, evidence, authority, and fail-closed behavior;
- complete a small bounded implementation task and explain what changed.

## Important boundary

This repository is a **training environment**. It does not contain the private APS source code, private architecture records, credentials, or production implementation details.

The Mini APS examples are intentionally simplified teaching examples.

## Learning flow

```text
Learn
→ Try
→ Break
→ Build
→ Connect to APS concepts
→ Quiz
→ Explain
→ Complete mission
```

## Structure

- Phase 1 — CODE: Python foundations for reading APS-style code
- Phase 2 — ENGINEER: Git, tests, contracts, services, and adapters
- Phase 3 — TRUST: verification, evidence, identity, freshness, authority, fail-closed
- Phase 4 — BUILDER: build and review a small Mini APS system

Progress is stored locally in the learner's browser.

## Run locally

Open `index.html` in a browser, or use GitHub Pages.
